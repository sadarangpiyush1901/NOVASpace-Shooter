# NOVASpace-Shooter
A high-performance 2D arcade space combat engine built from scratch using Python and Pygame with dynamic weapon upgrades and tiered enemy AI.

## 🚀 Key Technical Features
- **Dynamic Weapon Evolution:** Weapon systems progressively upgrade (Single Bolt → Twin Heavy Blasters → Triple Spread → Quad Ion Barrage) mapped dynamically to live score milestones.
- **Tiered Procedural Fleet:** 4 distinct enemy tiers (Scouts to Dreadnoughts) utilizing trigonometric oscillation flight paths and dynamic health scaling.
- **Vector Graphics Pipeline:** Custom mathematical geometry rendering for aircraft, rotating asteroids, and afterburner thrusters without pre-rendered sprite assets.
- **Physics & Collision Engine:** Real-time Euclidean distance collision checking across projectiles, breakable debris, and health restoration drops.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Engine:** Pygame
- **Core Concepts:** OOP, Trigonometric Motion Algorithms, Real-Time Game Loop
